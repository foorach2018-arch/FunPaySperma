# BADTRIP (◉_◉)

Бот для FunPay: сам выдаёт товары, отвечает покупателям, поднимает лоты. Вся управа — в Telegram.

## Что крутит

- **Авто-выдача** — товар улетает покупателю сразу после оплаты
- **Автоответчик** — отвечает на сообщения по заготовкам
- **Поднятие лотов** — по расписанию, вручную или по команде из TG
- **Ответы на отзывы** — свои тексты на каждую оценку
- **Приветствия** — встречи новых юзеров в чатах
- **Панель в Telegram** — всё настраивается с телефона, без правки конфигов
- **Плагины** — докидываешь файл, бот подхватывает
- **Прокси** — HTTP/SOCKS4/SOCKS5 для FunPay и Telegram отдельно
- **Чёрный список** — игнор и бан кто неугоден
- **Автообновление** — `/update` скачает и поставит свежую версию сам

## Установка

### Windows
1. Поставь [Python 3.10+](https://www.python.org/downloads/) (галку Add to PATH не забудь)
2. Запусти `Setup.bat` — поставит зависимости
3. Запусти `Start.bat` — бот проснётся

### Linux (VPS)
```bash
sudo bash install-badtrip.sh
```
Скрипт сам скачает бота из этого репо, поставит зависимости и создаст systemd-сервис.

## Первый запуск

При старте бот спросит три вещи:

- **golden_key** — кука сессии FunPay. Достань через расширение EditThisCookie: зайди на funpay.com → куки → скопируй значение `golden_key` (32 символа, начинается с `funpay-`)
- **Токен Telegram-бота** — создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен
- **Пароль панели** — придумаешь сам, им входишь в TG-панель

Конфиг сохранится в `configs/_main.cfg`. Дальше всё — в Telegram.

## Панель в Telegram

Напиши своему боту `/start`, введи пароль — и управляй:

| Команда | Что делает |
|---|---|
| `/menu` | главное меню |
| `/profile` | инфа об аккаунте |
| `/golden_key` | сменить golden_key |
| `/watermark` | подпись при авто-выдаче |
| `/black_list` | чёрный список |
| `/ban` / `/unban` | забанить/разбанить юзера |
| `/test_lot` | тестовый прогон лота |
| `/check_updates` | есть свежая версия? |
| `/update` | скачать и поставить обновление |
| `/create_backup` / `/get_backup` | бэкап конфигов |
| `/logs` / `/del_logs` | логи |
| `/sys` | нагрузка на систему |
| `/restart` / `/power_off` | перезапуск / выключение |

## Обновления

`/check_updates` — проверит, `/update` — поставит. Перед обновлением бот сам собирает бэкап `storage`, `configs` и плагинов.
